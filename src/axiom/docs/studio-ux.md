# 工作室里每天会用到的十件事

这些能力都在主界面里，不另开一套页面。

1. **导入数据**。把 CSV 或 Excel 拖进窗口，或用「文件 → 导入数据」。先预览，再把列映射成集合或参数，写入当前模型。编码会依次尝试 UTF-8、GB18030、GBK 和 Big5，Excel 可以选择工作表。写入可以撤销。
2. **参数表**。「数据」页用表格改常数右端、集合和参数。改完会写回 AML，并重新生成标准方程。Ctrl+Z / Ctrl+Y 撤销模型修改；标题、问题描述和对话框里的输入仍用它们自己的撤销。
3. **不可行诊断**。求解不可行时，结果页和「问题」面板用中文（可切英文）说明哪些约束冲突，并给出该把右端提高还是降低。点一条诊断会跳到标准方程里的对应约束。
4. **长时间求解**。求解过程中状态栏显示「求解 N%」。检查器里可以打开「完成时通知」和「提示音」。桌面壳用系统通知，浏览器里用 Notification API。提示音默认关闭。
5. **自动保存**。打开项目后，未保存的标题、问题和模型会写到本机草稿。下次打开同一项目时，如果草稿和已保存内容不同，会询问恢复或放弃。
6. **假设分析**。结果页可以拖动右端或参数，点「重算」对照基准和情景。打开「实时」后会在松手后自动重算。
7. **比较与版本**。两次已完成的求解会并排给出目标差和变量差。每次求解前自动留下「求解前」版本，也可以手动保存。回滚把那一版 AML 放回编辑器。
8. **算法建议**。模型就绪后，横幅用一句话说明为什么选这个求解器。求解器下拉框就是覆盖方式；和当前选择不同时，点「采用建议」即可切过去。
9. **行业模板**。「文件 → 行业模板」里有生产计划、运输、排班和设施选址，都带样例数据，可以一键试解。
10. **打包分享**。结果页的「打包分享」下载一个 zip：`model.aml`、`results.json`、`report.md` 和带「公理 Axiom」页眉的 `report.pdf`。
