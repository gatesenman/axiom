# 分析、多学科优化与兼容性

分析工作台在菜单「分析」和工具栏的图表按钮里。帮助菜单里的「兼容性」打开求解器与建模语言矩阵。长任务走 `POST /api/analyses`，用 `GET /api/analyses/{id}` 看进度，用 `POST /api/analyses/{id}/cancel` 取消。带 `project_id` 的任务会写进该项目的运行历史，求解器字段是 `analysis`。

智能体用词法规则提出分析。置信度达到 0.7 时，模拟对话会直接跑，并把结果交给分析标签。产品组合那句中文描述不含这些关键词，求解对话不会被分析抢走。

## 分析

| 种类 | 做法 |
| --- | --- |
| 局部灵敏度 | 对偶、既约费用、目标系数和右端的基范围。对偶符号用一次有限差分对齐模型方向。 |
| Morris / Sobol | SALib。Sobol 需要 pandas。SALib 缺失时 Morris 退回基本效应，Sobol 返回说明而不是空结果。 |
| 扫描 | 对右端或参数做一维、二维重解。 |
| 试验设计 | 全因子、分式因子、拉丁超立方、Sobol、Halton、中心复合、Box–Behnken。 |
| 代理模型 | 多项式响应面、普通 Kriging、径向基。交叉验证给出 RMSE、MAE 和 R²。 |
| 不确定性 | 蒙特卡洛和拉丁超立方传播，FORM（HL–RF）。 |
| 稳健 / 机会约束 | 情景两阶段、最坏情景、按正态分位数收紧的机会约束。 |
| 多目标 | 加权和、ε-约束、pymoo 的 NSGA-II / NSGA-III，以及超体积。 |
| 不可行与质量 | 删除滤波 IIS，加上最大违反、互补和既约费用间隙。 |
| 调度 | 调度模板的甘特图。三道工序的最优工期是 9。 |

## 多学科

学科是带输入、输出和耦合变量的函数。架构：

- MDF，MDA 用 Gauss–Seidel 或 Newton。
- IDF，耦合变量提升为设计变量，一致性作为约束。
- 协同优化（CO）。
- BLISS 的双层 SLSQP：学科块优化本学科变量，共享块优化没有属主的设计变量。这是可运行的双层分解，不是 1998 年那篇用灵敏度导数的原始 BLISS。
- OpenMDAO 的 `NonlinearBlockGS` 加 SLSQP。Windows 轮子是纯 Python，可以打进安装包。

模板：Sellar（发表最优值约 3.18339）、机翼尺度、供应—工厂—市场。N2 图可以点开耦合。收敛历史记录目标、约束违反和 MDA 残差。

机翼上的协同优化能找到可行点，但目标比 MDF / IDF 差。测试只要求 MDF 与 IDF 一致且可行。

## 图

图沿用论文风格的 `AcademicFigure`：帕累托（二维，以及第三目标非零时的斜投影）、平行坐标（轴上拖拽刷选）、散点图矩阵、响应面等高线与三维网格、主效应和交互、Sobol 条形、Morris μ*–σ、龙卷风、收敛、直方图和经验分布、相关热图、N2、调度甘特。点一个设计，平行坐标、矩阵和帕累托一起高亮。放大缩小用工具栏按钮。悬停给出有效数字和单位。PNG、SVG、PDF 按 300 dpi 导出；有数据表时可以复制 CSV 和 LaTeX 表格。

## 兼容性矩阵

`GET /api/compatibility?execute=false` 只做能力判断。`execute=true` 会对每个问题类真正求解，并对每种语言做导出再导入。求解器不接受该类、未安装或许可不够时，格子带中英原因，状态是 `unsupported` 或 `not_installed`，不会假装成功。测试要求每个（问题类，非局部求解器）格子都存在，失败格子有英文原因，可用且接受的组合状态是 `ok`。

CBF 写出器不发出二阶锥，所以锥约束不在 CBF 往返里。OR-Tools 只有导出。COPT 声明了 SDP，但没有安装时矩阵写明未安装，测试不要求它解 SDP。
