# 标准方程

公理在调用任何求解器之前，先把已经校验通过的 AML 模型写成标准数学形式。这一步失败时，求解不会开始。

## 生成时机

1. 建模器校验 AML。
2. 系统展开模型，写出标准方程。写不出来就结束这次运行，并在智能体日志里记为「标准方程未能生成」。
3. 人工闸门可以停在问题上、模型上，以及标准方程上。自动批准会把这三步记成系统批准，但不会跳过方程生成。
4. 方程生成成功并且闸门通过之后，求解器竞赛才启动。

编辑器里的 AML 一变，标准方程就按同一套规则重算。页面上的每一条展开方程都标着它对应的约束名；点约束名会高亮那几条方程。

## 三种写法

线性规划写成

\[
\max\; c^{\mathsf T} x
\quad\text{或}\quad
\min\; c^{\mathsf T} x
\]

约束按行分成 \(A_{\le} x \le b_{\le}\)、\(A_{=} x = b_{=}\)、\(A_{\ge} x \ge b_{\ge}\)，并列出变量界 \(\ell \le x \le u\)。

混合整数模型在上面的基础上标出整数集 \(\mathcal{I}\) 和 0-1 集 \(\mathcal{B}\)。

非线性模型写成 \(\min/\max\; f(x)\)，约束保留 \(g(x)\) 的比较式。经典的松弛等式标准形只适用于线性模型，非线性页会明确说明这里不生成。

带下标的约束同时给出指标形式（\(\forall i \in I\)）和展开后的每一条方程。展开方程的名字与 AML 里的约束名一致，例如 `labor`、`cover[A]`。

## 经典标准形

对线性模型，每条不等式再写成等式：

- \(a^{\mathsf T} x \le b\) 增加非负松弛变量 \(s\)，变成 \(a^{\mathsf T} x + s = b\)。
- \(a^{\mathsf T} x \ge b\) 减去非负剩余变量 \(t\)，变成 \(a^{\mathsf T} x - t = b\)。
- 有限上界 \(x \le u\) 写成 \(x + s_{ub} = u\)。
- 下界为 0 的变量直接进入非负集合。下界为负数或变量自由时，先平移或拆成两个非负变量，再写等式。

整数和 0-1 限制留在集合说明里，不写进松弛变量。松弛变量和剩余变量都是连续且非负的。

产品组合

\[
\begin{aligned}
\max\quad & 40 x_A + 30 x_B \\
& 2 x_A + 3 x_B + s_{\mathrm{labor}} = 120 \\
& 3 x_A + x_B + s_{\mathrm{material}} = 90 \\
& x_A, x_B, s_{\mathrm{labor}}, s_{\mathrm{material}} \ge 0
\end{aligned}
\]

背包问题会在容量约束上加松弛，并为每个 0-1 变量的上界写一条等式，同时列出 \(\mathcal{B}\)。

## 界面与导出

文档页「标准方程 / Standard Equations」用 KaTeX 显示矩阵形式、展开方程和经典标准形。可以分别复制 LaTeX、纯文本和 MathML。

Markdown 和 PDF 报告包含同一段标准方程。Excel 报告里有 Equations 工作表。

接口 `POST /api/standard-form`，请求体 `{ "dsl": "..." }`。模型还不合法时返回 `ok: false`，不调用求解器。
