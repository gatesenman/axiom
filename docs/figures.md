# 学术图

结果页上的图按运筹学论文的版式排，而不是仪表盘配色。每张图都坐在浅色衬底上，深色界面里也保持同一块纸色，方便直接放进文稿。

## 版式

- 刻度用衬线字体（Liberation Serif、Georgia、Noto Serif SC），坐标从论文习惯的实线网格读数。
- 标题写清对象，副标题写清单位或坐标含义。图下有说明，中文为「图 n」，英文为「Fig. n」。
- 柱形无圆角、无动画。系统开启减少动效后，图内过渡同样关闭。
- 悬停显示精确数值。龙卷风图和影子价格图的提示里带约束或参数名。可行域图在靠近边界时写出约束名和坐标；拖拽框选放大，双击还原。龙卷风图和影子价格图底部的条带也可以刷选缩放。

## 图的种类

已求解的运行会尽量画出下面这些图。某一类数据不存在时，那一张不编号、不占位。

| 图 | 数据 |
| --- | --- |
| 决策变量 | 最优解里各变量的取值，纵轴从 0 起 |
| 灵敏度跨度 | 参数 ±10% 扰动下目标值的最高减最低 |
| 情景目标 | 基准与右端 ±10% 情景的目标值 |
| 龙卷风图 | 相对基准目标的下摆（左）与上摆（右） |
| 影子价格 | 求解器给出的约束对偶值 |
| 可行域 | 恰好两条连续决策变量的线性模型；折线为约束，点为最优解 |
| 松弛直方图 | 约束松弛量的频数 |
| 情景相关 | 决策变量在各情景上的 Pearson 相关 |
| 求解器收敛 | 可行或最优解的运行时间（秒）对目标值 |
| Pareto 前沿 | 模型里至少有两个目标时，按权重扫描得到的非支配点 |

整数变量或超过两个连续决策变量时，不画二维可行域。单目标模型不画 Pareto 前沿。

旧的运行结果里如果没有几何数据，结果页会用当前模型再请求 `POST /api/figures`，并把这次解的变量标成最优点。

## 导出

每张图右上角有三个按钮：

- **PNG**：按 300/96 的像素倍率栅格化，纸色底。
- **SVG**：矢量，适合再导入绘图软件。
- **LaTeX**：复制一段 `\begin{figure}...\end{figure}`，文件名是 `fig-<id>.pdf`。

Markdown 报告在文末附上同样的图题和 LaTeX 片段。PDF 报告用横向条形图嵌入灵敏度跨度与影子价格，并写上可行域的图题。报告页眉仍是「公理 Axiom」。

## 和测量用的三张图

变量、情景、灵敏度跨度这三张图的数据合同不变：变量和情景是纵向柱，灵敏度是横向跨度柱，容器上分别是 `data-chart="variables"`、`scenarios`、`sensitivity`。刷选条只出现在龙卷风图和影子价格图上，不会进这三张图的测量区域。灵敏度图的副标题仍是「横条是目标值在 ±10% 扰动下的跨度（最高减最低）。」
